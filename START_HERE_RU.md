# Запуск TRACE-PIA

Основной репозиторий: `Vados992/TRACE-v0.1-Engineering-MVP-`. Реализованы API, PostgreSQL, Evidence Vault, временной граф, сверка имущества, проверка контекста конфликтов интересов, дела, аудит и раздельные внутренний/публичный интерфейсы. Это рабочая архитектура для дальнейшего внедрения, без заявления о сертификации или официальном подключении к закрытым государственным системам.

## Локально с Docker

Установите Git, Docker с Compose v2 и Python 3.12+. В PowerShell:

```powershell
git clone https://github.com/Vados992/TRACE-v0.1-Engineering-MVP-.git
cd TRACE-v0.1-Engineering-MVP-
Copy-Item .env.example .env
docker compose up --build -d --wait
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.lock
.\.venv\Scripts\python.exe scripts/smoke.py
```

Откройте `http://127.0.0.1:8000/ui/`. Ключ разработки: `trace-dev-analyst-only`. Отдельные роли: `trace-dev-reviewer-only`, `trace-dev-publisher-only`, `trace-dev-admin-only`. В production эти ключи запрещены. Ключ не сохраняется после перезагрузки страницы.

Публичный портал: `/public/`, документация API: `/docs`, схема: `/openapi.json`.

Обязательны PostgreSQL 17, API и постоянное хранилище Evidence Vault. Redis, Neo4j, OpenSearch и внешнее S3 не обязательны. Граф и поиск путей работают через PostgreSQL. Схема и источники создаются автоматически; синтетические люди при запуске не загружаются.

## Реальные данные

```powershell
.\.venv\Scripts\python.exe scripts/live_validation.py --sources gleif ted eurlex ocds
.\.venv\Scripts\python.exe scripts/live_validation.py --sources openownership
```

Коннекторы действительно обращаются к публичным HTTPS-сервисам. GLEIF показывает бухгалтерское родительство; TED — извещения и явно опубликованные суммы присуждения; EUR-Lex — отношения правовых документов; Find a Tender — OCDS. Open Ownership предоставляет опубликованный UK-снимок BODS 0.4 от 11 марта 2025 года, а не свежую копию Companies House. Доступность публичных источников может меняться; ошибки видны и не заменяются выдуманными данными.

Для BODS/PPDS других поставщиков задайте реальные разрешённые URL и, при необходимости, секреты по [CONNECTORS.md](CONNECTORS.md). Закрытые реестры, налоговые/банковские данные и институциональные интерфейсы требуют законного доступа, ключей и подтверждённого формата. Таких полномочий репозиторий не выдумывает.

Загрузите источник в кабинете, найдите объект, выберите начальную/конечную точку Path Finder и откройте происхождение связи. Импорт OCDS/BODS сохраняется как UNVERIFIED до проверки отдельным рецензентом. Для исследовательского просмотра этих записей можно явно выключить фильтр подтверждённых связей. Импорт деклараций имущества требует реальных чисел и ссылок на компоненты; отсутствующие сведения дают INCOMPLETE, не выдуманный ноль.

Дело создаёт аналитик, рецензент проверяет и готовит обезличенный публичный текст, третий сотрудник публикует. Обжалование убирает текущую публикацию и открывает повторную проверку. Связь, сигнал или расхождение не означают виновность.

## Сервер

```powershell
.\.venv\Scripts\python.exe scripts/bootstrap_production.py
docker compose --env-file .env.production -f compose.production.yml up --build -d --wait
.\.venv\Scripts\python.exe scripts/production_smoke.py
```

Секреты создаются в игнорируемых `.env.production` и `.production-keys.json`; выдайте роли отдельным людям. Публичный gateway слушает локальный порт 8080, внутренний кабинет — 8000. Для внешнего доступа настройте TLS, внутреннюю сеть/VPN, резервные копии и реальные правила обработки персональных данных. См. [DEPLOYMENT.md](DEPLOYMENT.md), [SECURITY.md](SECURITY.md), [OPERATIONS.md](OPERATIONS.md).

Без Docker установите PostgreSQL, укажите его DSN в `.env`, выберите `EVIDENCE_BACKEND=filesystem`, выполните миграции и `python scripts/serve.py`. Этот запуск учитывает совместимость Windows/psycopg. Не используйте общедоступные dev-пароли на сервере.

Тестовые данные в `fixtures/demo` предназначены только для отдельной проверочной базы. Рабочий запуск использует реальные загрузки; сценарий `scripts/demo.py` включается оператором отдельно. Результаты проверок и ограничения: [VALIDATION_REPORT.md](VALIDATION_REPORT.md).

## Восстановление картины прошлого

В интерфейсе появились независимые поля «Известно системе на» и периода действия фактов. Для момента решения укажите одинаковые даты начала и конца действия, а отдельно — момент доступности сведений. Доказательства открываются в том же временном срезе. Более поздние загрузки и проверки не попадают в прежний срез. Полная история начинается с миграции 009: утраченную историю прежней версии система не выдумывает. Инструкции обновления PostgreSQL: [TEMPORAL.md](TEMPORAL.md).
